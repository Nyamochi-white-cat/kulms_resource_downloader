# KULMS Resource Downloader

京都大学の学習支援システム KULMS（Sakai LMS）の「リソース」ページで、ファイル/フォルダを扱いやすくダウンロードするための非公式 Chrome 拡張機能です。

## 主な機能

- ファイル/フォルダ行のメニューにダウンロード操作を追加
- フォルダダウンロード時にツリー表示で対象ファイルを選択可能
- フォルダ構造を維持したまま保存（展開保存）
- ZIP 形式での一括保存に対応

## インストール

1. このディレクトリをダウンロードまたはクローン
2. `chrome://extensions/` を開く
3. 「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」から本ディレクトリを選択

## 使い方

1. KULMS のリソースページを開く
2. 各アイテム行のダウンロードリンクをクリック
3. フォルダの場合はモーダルで対象・保存形式（展開/ZIP）を選んで開始
