# KULMS Resource Downloader

京都大学の学習支援システム (KULMS / Sakai LMS) の「リソース」ページにおいて、ファイルやフォルダ構造を直接かつ柔軟にダウンロードできるようにするための非公式Chrome拡張機能です。

> **Note:** このプロジェクトの初期プロトタイプおよび主要な仕組みは、ユーザーとAIアシスタント（Google Agentic AI システム）とのペアプログラミングによって作成されました。

## 特徴 (Features)

- **便利なダウンロードボタンの追加:** ファイル/フォルダのプルダウンメニュー内の「プロパティを表示」下に「ダウンロード」ボタンを行に直接追加します。
- **選択的ダウンロード機能:** フォルダをダウンロードする際、その中身がツリー状にプレビュー表示されます。必要なファイルのみにチェックを入れてダウンロードすることが可能です。
- **フォルダ階層の自動復元 (Raw展開):** `chrome.downloads` API や File System Access API を駆使することで、複雑なフォルダ構造をそのままの形でユーザーのローカル（ダウンロードフォルダや任意の場所）へ一括保存できます。
- **ZIP圧縮サポート:** フォルダをひとつのZIPファイルに圧縮して保存することも可能です。

## インストール手順 (Installation)

Chromeウェブストアには公開されていないため、デベロッパーモードを利用して手動で追加します。

1. このリポジトリを `Clone` するか、ZIPでダウンロードして解凍してください。
2. Chromeブラウザを開き、アドレスバーに `chrome://extensions/` と入力して移動します。
3. 画面右上の **「デベロッパー モード」** のトグルをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 先ほどダウンロード（解凍）したフォルダ（`manifest.json` が含まれているディレクトリ）を選択します。
6. インストール完了！KULMSのタブを開き直すか、リロード（F5）してお使いください。

## 使い方 (Usage)

1. リソースページにアクセスすると、各アイテム行の右側に「ダウンロード」というリンクが現れます。
2. 単一ファイルの場合は、クリックするだけで標準のダウンロードが開始されます。
3. フォルダの場合は、**ダウンロード設定のモーダル**が表示されます。
   - ツリーの中からダウンロードしたいファイルを選択します。
   - 「保存形式（フォルダ展開 or ZIP）」と「保存先（標準おまかせ or エクスプローラーで細かく指定）」を選び、「ダウンロード開始」をクリックしてください。

## 技術仕様 (Tech Stack)

- **Manifest V3:** 最新のChrome拡張機能アーキテクチャに準拠。
- **JSZip:** フロントエンドでの動的なZIP生成処理。
- **File System Access API & chrome.downloads:** セキュアで柔軟なファイル保存（「システムファイルが含まれているため〜」といったブラウザ起因の制限エラーを迂回する堅牢な仕様）。
- **Vanilla JavaScript:** 複雑な外部フレームワークなしで動作。
